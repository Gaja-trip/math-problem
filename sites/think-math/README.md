# 생각수학

수학경시대회 준비를 위한 한국어 학습 앱입니다. 개인 학습 기록은 브라우저에 저장하며, 배포된 앱은 기존의 비공개 접근을 유지합니다.

## 실행

Node.js 22.13 이상에서 `server-runtime/`의 잠긴 의존성을 설치하고, 프로젝트 루트에서 `node scripts/prepare-server.mjs`를 실행하세요. `server-runtime/`에서 `npm run dev -- --port 4173 --hostname 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:4173/learning/index.html`을 여세요. 기존 화면 소스는 `dist/`에 보존하며 서버 코드는 별도 `server-runtime/`에 있습니다.

## 기능

- 초등 1학년부터 중등 3학년까지 학년 선택
- 8개 개념 영역과 개념 확인 문제, 조각을 선택하는 분수 시각화
- 학년별 4문항, 총 36개 창작 연습문제: 힌트, 생각 정리, 자동 채점과 단계별 해설
- 동치 분수·소수·한글 단위가 있는 숫자 답안 채점
- 오답 복습, 북마크, 학습 목표와 최근 7일 기록
- 텍스트 문제 직접 등록 및 개념 연결
- HME 공식 자료실 46개 회차에 연결된 문제지·풀이지 407쌍의 목록과 원문 연결
- 공식 정답표에서 번호·답을 대조한 4,748문항 온라인 풀이·자동 채점
- 2026년 상반기 초1~중3 전 학년 225문항 포함
- 공식 정답표·해설 원문 표시, 객관식 선택, 숫자·분수의 정확한 유리수 비교
- 원본 파일의 SHA-256이 수집 당시와 다르면 원문 표시와 채점을 중단
- 직접 받은 PDF 등록·열람·확대·페이지 이동·다운로드, 문항별 정답표 등록, 자동 또는 자기 채점
- 문제 선택, 제목과 풀이 공간 설정, 정답·해설 선택, A4 PDF 다운로드와 인쇄
- JSON 학습 기록 내보내기

## HME 원본 상태와 범위

기출 자료실에서 학년과 연도를 선택하고 페이지 번호로 회차를 탐색합니다. ‘전체 문제 풀기’를 누르면 해당 회차의 문항을 위에서 아래로 풀 수 있습니다. 입력한 답과 풀이 메모는 이 기기에 저장됩니다. 답안을 한 번에 제출하면 문항별 정답·오답·미응답, 환산 점수, 공식 해설집의 모든 페이지가 표시됩니다. 같은 답안의 중복 제출은 학습 기록을 늘리지 않으며, 수정한 답안은 다시 제출할 수 있습니다. 미응답은 학습 기록과 오답노트에 반영하지 않습니다. 원본 여러 쪽 보기에서도 문제지와 풀이지의 모든 페이지를 이어서 표시합니다.

2026년 10월 20일 사용자가 `https://hme.chunjae.co.kr/hme/hme_data/hme_preque.asp`를 지정하고 천재교육에 직접 로그인한 후, 실제 게시된 수학 문제지와 공식 풀이지 407쌍을 확보했습니다. 수집 목록과 파일 해시를 기록했으며 국어 자료는 포함하지 않았습니다.

공식 정답표의 1~25번을 pypdf와 pdfplumber로 각각 추출해 정확히 일치하는 답만 사용합니다. 현재 정답표 대조가 끝난 자료는 194개이며, 문항 위치까지 확인된 4,748문항을 온라인으로 풀 수 있습니다. 오래된 자료는 총 문항 수가 다르거나 글꼴 인코딩이 불명확할 수 있어 전체 원문을 제공하되 확인되지 않은 답은 자동 채점하지 않습니다. 모든 회차의 모든 문항을 검증했다는 의미는 아닙니다. 공통 지문·도형·수식은 원본 그대로 표시하고, 공식 정답표와 풀이도 원문으로 확인합니다.

온라인 문항이 있는 190세트의 원본 PDF 380개를 앱에 포함했습니다. 수집·묶음 생성 시와 학습 화면에서 열 때마다 수집 당시의 SHA-256과 비교하며 일치하지 않으면 채점하지 않습니다. 자동 채점 자료는 HME 서버에 별도로 연결하지 않고 학습할 수 있습니다. 정답 대조 대기 자료는 HME의 공식 원문 링크를 제공하며 HME 로그인이 필요할 수 있습니다. 수집한 전체 814개 원본은 소스의 `assets/hme/files/`에 보존합니다. 임의 URL을 가져오는 프록시는 제공하지 않으며 천재교육 계정 정보나 쿠키를 수집·보관하지 않습니다.

직접 등록한 PDF는 기존처럼 IndexedDB에 보관하며 정답표를 직접 입력하거나 자기 채점을 할 수 있습니다. 기본 창작 연습문제 36개는 별도 탭에서 제공합니다.

## 저장과 PDF

풀이 기록, 설정, 직접 등록한 문제는 localStorage에 저장합니다. PDF 원본은 IndexedDB에 저장합니다. 서버로 전송하지 않으며 기기·브라우저 간 동기화는 지원하지 않습니다. 브라우저 데이터를 삭제하면 기록이 지워집니다. JSON 내보내기에는 원본 PDF가 포함되지 않습니다.

학습지 PDF는 브라우저 Canvas에서 한글을 렌더링한 후 JPEG 페이지로 PDF에 포함하는 방식입니다. A4, 1240 × 1754 픽셀로 출력되며 정답과 해설은 별도 페이지에 포함됩니다. 이 방식은 패키지나 외부 API가 필요 없고 기기 한글 글꼴을 사용합니다. PDF 텍스트 검색·선택과 수식 조판(LaTeX)은 지원하지 않습니다. 화면 글꼴의 Google Fonts 요청에 실패해도 시스템 한글 글꼴로 동작합니다.

원본 PDF 열람은 앱에 포함된 Mozilla PDF.js 5.6.205를 사용합니다. 외부 CDN에 의존하지 않으며 CMap, 표준 글꼴, WASM 보조 파일을 포함합니다. 원본의 텍스트 검색·선택은 현재 제공하지 않습니다. 라이선스는 `dist/vendor/pdfjs/LICENSE`에 있습니다.

## 확인

`npm test`는 채점, 문항 데이터, 기록 집계, 저장 복원, 한국 시간 날짜, PDF 객체 및 xref를 확인합니다. `npm run check`는 JavaScript 구문을 확인합니다.
